Permet à l'application d'appeler Claude Managed Agents en votre nom. Créez-la dans la Claude Console → Settings → API Keys (platform.claude.com/settings/keys). Managed Agents est activé par défaut sur les comptes API. Utilisez de préférence un workspace dédié : les vaults sont partagés à l'échelle du workspace.
