System instructions

System instructions are rules that apply to every workflow, for every user. They take precedence over what a workflow description says: when a description contradicts them, Maestro rewrites the workflow to comply and lists each change under Adjusted to system instructions on the design. Maestro also receives them at the start of every run. {% if can_edit %}Only admins can edit them. When you change them, existing workflows are marked instructions changed so their owners can regenerate the design; their runs apply the new instructions right away.{% else %}Only admins can edit them.{% endif %} They never override Maestro's built-in rules for driving Upsun Dispatch.
